# Markdown PDF Plus themes

Add to VS Code **User settings** (for global access), adapting the CSSPath to your chosen location:

```json
"markdown-preview-github-styles.colorTheme": "auto",
"markdown-pdf-plus.pageSize": "letter",
"markdown-pdf-plus.usePageStyleFromCSS": true,
"markdown-pdf-plus.CSSPath": "~/.config/Code/markdown-themes/pdf-light.css"
```

To export a dark PDF, change `markdown-pdf-plus.CSSPath` to `~/.config/Code/markdown-themes/pdf-dark.css`, then run **Markdown PDF Plus: Export PDF**. Switch it back to light for print-oriented PDFs.

**Mermaid diagram caveat:** your original `.md` documents contain *explicit* Mermaid theme colors, which an outer CSS file cannot reliably retheme. Use `SAM_Overview_Proposal_Light.md` for light diagrams and `SAM_Overview_Proposal_Dark(1).md` for dark diagrams until the diagrams are parameterized or generated by a theme-aware script.

The CSS is scoped to `@media print` to avoid overriding the GitHub preview. CSS results may depend on PDF Plus's internal stylesheet ordering; if some rules are overridden, inspect export output and increase selector specificity.
